# 仓库专属提示词设计

## 背景

`kaochang-controller-android11` 是安卓11现场上位机 app 的独立维护仓库。从 `1.3.01` 起，该仓库作为老稳定版本维护，不再默认跟随 `D:\LeYe\cl-sausage-controller` 的分支逻辑。

## 目标

在仓库根目录提供 `AGENTS.md` 和 `CLAUDE.md`，让 Codex 和 Claude Code 在本仓库内使用一致的协作规则。

## 设计选择

采用规则型提示词，主轴是稳定、可回退、少扩散。该写法比长篇背景说明更直接，适合老稳定现场版本维护。

## 规则范围

- 仓库定位：安卓11现场上位机独立维护仓库。
- 最高原则：稳定、可回退、少扩散。
- 修改边界：只处理强相关问题，保护用户未提交改动。
- 现场设备行为：影响控制链路的改动必须先说明影响、回退和验证。
- 版本与打包：明确 APK/AAB 区分、蒲公英上传要求、Gradle 任务和正式签名依赖。
- 验证要求：能本地跑的验证优先跑，发包和版本相关改动要跑构建验证。
- 日志、状态和编码：中文含义清晰，避免乱码和口径漂移。
- Git 提交：中文 commit message，说明影响、验证和风险。

## 文件策略

`AGENTS.md` 与 `CLAUDE.md` 内容保持一致，后续修改需要同步，避免 Codex 和 Claude Code 执行口径分叉。
